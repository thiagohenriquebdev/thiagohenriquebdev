## 📚 Conhecimentos técnicos

- **Orientação a Objetos:** encapsulamento, herança, polimorfismo e uso de enums para regras de domínio
- **APIs REST:** endpoints com `GET`, `POST`, `PUT` e `DELETE`, uso de `ResponseEntity` e status HTTP
- **CRUD completo** organizado em camadas: `Resource` → `Service` → `Repository`
- **JPA / Hibernate:** mapeamento de entidades e relacionamentos `@OneToMany`, `@ManyToOne`, `@ManyToMany`, `@OneToOne` e chave composta com `@EmbeddedId`
- **DTOs** para separar os dados de entrada e saída da API
- **Tratamento de exceções** centralizado com `@ControllerAdvice` e exceções personalizadas (`ResourceNotFoundException`, `DataBaseException`)
- **Validação de dados** com Bean Validation (`@Valid`)
- **Banco de dados:** SQL, MySQL, H2 para desenvolvimento e configuração de datasource no Spring
- **Versionamento** com Git e GitHub

## 🚀 Projetos

### 💈 [GestorDeBarbearia](https://github.com/thiagohenriquebdev/GestorDeBarbearia)

API REST para gestão de uma barbearia: **fila de atendimento**, clientes, produtos, categorias e pagamentos.

- Fila de atendimento: entrada do cliente, chamada do próximo e finalização do atendimento
- CRUD de clientes, produtos e categorias
- Registro de itens consumidos no atendimento, com chave composta (`@EmbeddedId`)
- Pagamento vinculado ao atendimento, com status e forma de pagamento em enums
- Relatório de estoque de produtos
- Tratamento global de exceções e validação das requisições

### 📦 [CRUD-Endpoint](https://github.com/thiagohenriquebdev/CRUD-Endpoint)

API REST de **controle de estoque de produtos**, com CRUD completo.

- Endpoints de cadastro, consulta, atualização e remoção de produtos
- DTOs de requisição e resposta (`ProdutoRequest` / `ProdutoResponse`)
- Tratamento global de exceções com `ResourceNotFoundException`
